Important DevOps Concepts
------Continuous Integration (CI)
Continuous Integration is the practice of frequently integrating code changes into a shared repository and automatically validating them through builds and tests.
Example: A developer pushes code to GitHub, and a workflow automatically runs tests.
------Continuous Delivery (CD)
Continuous Delivery keeps software in a deployable state after the required build and testing stages. A production release may still require manual approval.
------Continuous Deployment
Continuous Deployment automatically releases qualifying code changes to production when the pipeline requirements are satisfied.
------Infrastructure as Code (IaC)
Infrastructure as Code means defining and managing infrastructure through machine-readable configuration files rather than relying entirely on manual setup.
Example tools: Terraform and AWS CloudFormation.
------Configuration Management
Configuration management helps maintain consistent system configurations across servers and environments.
Example tool: Ansible.
------Monitoring and Logging
Monitoring tracks measurements such as CPU usage, memory utilization, response time, and error rates.
Logging records events generated by applications and systems.
Together, these practices help teams investigate problems and maintain application reliability
